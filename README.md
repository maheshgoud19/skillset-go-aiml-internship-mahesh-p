## Weekly Progress

### Week 1 – Python, Mathematics & ML Foundations
Completed all four tasks. The week reads as one connected story rather than four
disconnected exercises:

- **1.1 Python Fundamentals** – 8 topic-wise exercise files plus a 16-assertion self-check
  suite covering invalid input, not just the happy path.
- **1.2 Data Cleaning & EDA** – cleaned a 184-row wine export down to 178 clean rows,
  documenting the reason for every decision; 6 EDA questions, each with a chart and a
  written interpretation. Predicted that `flavanoids`, `proline_mg_l` and
  `color_intensity` separate the cultivars.
- **1.3 Math for ML** – statistics, probability, linear algebra and calculus solved by
  hand with steps shown, verified in NumPy, each linked to where it appears in an ML
  algorithm.
- **1.4 Scikit-Learn Models** – a regression and a classification workflow, each with a
  dummy baseline first. **The EDA prediction from 1.2 was confirmed**: those same three
  features came out as the top three by importance.
